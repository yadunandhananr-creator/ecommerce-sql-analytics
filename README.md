# E-Commerce Sales & Customer Analytics using MySQL

## Project Overview
This project focuses on analyzing e-commerce sales and customer data using MySQL. It demonstrates database design, SQL querying, sales analysis, customer analysis, and reporting.

## Objectives
- Design a relational database for an e-commerce system.
- Analyze sales and payment information.
- Retrieve customer purchase history.
- Generate monthly sales summaries.
- Practice SQL queries and database management.

## Database Tables
- `customers`
- `sellers`
- `products`
- `orders`
- `order_items`
- `payments`

## Tools & Technologies
- MySQL
- MySQL Workbench
- SQL

## Project Structure
- `sql/` – SQL scripts and queries
- `diagram/` – ER diagram and MySQL Workbench model
- `report/` – Project report in PDF and Word formats
- `screenshots/` – Screenshots of query outputs

## Key Features
- Monthly sales summary using a SQL view.
- Customer purchase history using a stored procedure.
- Payment-method-wise sales analysis.
- Relational database design with an ER diagram.

## How to Use
1. Download or clone this repository.
2. Open MySQL Workbench.
3. Create or select the project database.
4. Execute the SQL script provided in the `sql` folder, following the instructions in the project report.
5. Run the required queries to explore the analysis.
